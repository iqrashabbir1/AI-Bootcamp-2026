# Day 02 – Smart Calculator Assistant

## 📌 Project Overview

The **Smart Calculator Assistant** is a Python command-line application that performs basic arithmetic operations based on user input. This project demonstrates the use of conditional statements, functions, user input, and error handling.

---

## 🎯 Learning Objectives

By completing this project, I learned:

* Writing reusable Python functions
* Using `if`, `elif`, and `else` statements
* Accepting user input with `input()`
* Performing arithmetic operations
* Handling division by zero
* Displaying formatted output

## 🚀 How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the program:

```bash
python calculator.py
```
